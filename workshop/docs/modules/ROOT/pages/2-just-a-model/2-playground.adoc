= Playground

[role="_abstract"]
Now that you have a model deployed, you probably want to use it and verify that it works.

In {productname-short} you can use the *Playground* to send messages to the model. +
Use it to confirm the model works and to see how it responds to different messages.

== Procedure

. Navigate to *Gen AI studio → Playground* in {productname-short}. Ensure you select your project.

. Click *Create Playground*, select your deployed model, leave *Max Tokens* empty, and then click *Create*.
+
image::2-just-a-model/create-playground.png[Create Playground]

. After a couple of minutes, you will have the playground ready to use. 

== Verification

Try writing a few things to it, starting with Hi, and see how the model behaves. If everything is set up correctly you will get a polite answer back.

image::2-just-a-model/playground-response.png[Playground Response]

.Increase the timeout limits when running on CPU
[%collapsible]
====
Responses can take longer than the default 30-second timeout allows. There are two timeouts in the stack that both need to be increased. You can do this in two ways:

*Option 1, OpenShift CLI (web terminal or local):*

[source,terminal]
----
oc apply -n <your-project-name> -f https://raw.githubusercontent.com/rh-aiservices-bu/hospital-helpdesk/main/setup/increase-timeouts-job.yaml
----

*Option 2, OpenShift console (Import YAML):*

In the OpenShift console, click *+* in the navigation bar, select *your project*, and paste the following:

[.lines_space]
[.console-input]
[source,yaml]
----
---
apiVersion: v1
kind: ServiceAccount
metadata:
  name: demo-setup
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: demo-setup-edit
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: edit
subjects:
  - kind: ServiceAccount
    name: demo-setup
---
apiVersion: batch/v1
kind: Job
metadata:
  name: increase-timeouts-through-oc
spec:
  selector: {}
  template:
    spec:
      containers:
        - args:
            - -ec
            - |-
              echo -n 'Setting up S4 instance and connections'
              oc apply -f https://github.com/rh-aiservices-bu/hospital-helpdesk/raw/main/setup/increase-timeouts-job.yaml
          command:
            - /bin/bash
          image: image-registry.openshift-image-registry.svc:5000/openshift/tools:latest
          imagePullPolicy: IfNotPresent
          name: increase-timeouts-through-oc
      restartPolicy: Never
      serviceAccount: demo-setup
      serviceAccountName: demo-setup
----

After the job completes, the model has up to 10 minutes to respond without timing out.
