= Export your playground code

[role="_abstract"]
Before you move away from the Playground, extract the code so that you can use it later.

NOTE: If you cannot save the code locally, skip this step. Instructions for extracting the code again appear later, when you use the code.

== Prerequisites

- The Playground is set up and tested, as described in xref:2-just-a-model/2-playground.adoc[2.2. Chat with your model in the playground]

== Procedure

. Click *View code*.
If the button is not active, send a message to the chat. You can send this message:
+
`A patient just called asking how to get to the radiology department from the main entrance. Can you help me draft a response?`
+
image::3-move-to-code/view-code.png[View code]

. Copy the full code. You can use the copy button in the modal.
+
image::3-move-to-code/copy-code.png[Copy code]

. Save the code somewhere. You will need it in xref:3-move-to-code/5-run-playground-code.adoc[3.5. Run the playground code], where you run it.

== Next step

Create a workbench, which is a coding environment, in xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench] so you have somewhere to run the code you saved.
