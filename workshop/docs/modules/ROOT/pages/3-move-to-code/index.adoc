= Move to code

[role="_abstract"]
So far, you have been using the Playground to interact with your model. The Playground is good for testing, but it does not deploy production AI agents. To do that, you must move to code.
In this chapter, you explore the code version of what you ran in the Playground. The Playground provides instructions for moving your current setup into code.

Start by extracting the code from the Playground in xref:3-move-to-code/1-playground-to-code.adoc[3.1. Export your playground code]
