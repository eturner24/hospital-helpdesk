= Ingest documents with a pipeline

[role="_abstract"]
Now that you have used RAG from the Playground, you can do the same thing in code.
There are two parts to it: one for ingesting the documents, and one for querying the model using those documents.
Start here with the ingestion part, which you build as a pipeline so you can trigger it whenever new documents are added.

== Prerequisites

- You have a workbench set up according to xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench].
- You have set up the playground as described in xref:2-just-a-model/2-playground.adoc[2.2. Chat with your model in the playground].

== Procedure

. Navigate to your workbench. If it is not open, find it through the {productname-short} dashboard > Projects > your project.

. In the workbench, open the file called `rag_pipeline.py`. This is a pipeline built with the Kubeflow Pipelines Python SDK. Review how it is set up.
This pipeline contains the steps needed to chunk and ingest a new document into your RAG database, specifically this document: link:https://github.com/rh-aiservices-bu/hospital-helpdesk/blob/main/it_facilities_guide.pdf[it_facilities_guide.pdf,window=_blank]
The document has already been uploaded into an S3 bucket, which the pipeline downloads from. This is the bucket you set up in xref:1-setup/2-data-connections.adoc[1.2. Connect to your data].

. Run the code to compile and run the pipeline by clicking the play button in the top menu.
+
image::5-rag/run-pipeline.png[Run Pipeline]

== Verification

. The following output appears:
+
image::5-rag/console-output.png[Console Output]

. You can now view the pipeline run in the {productname-short} dashboard. Select *Develop & train* > *Pipelines* > *Runs* from the left menu, then click the run that appears.
+
image::5-rag/pipeline-run.png[Pipeline Run]

. Track the pipeline progress here. After a few minutes, both steps turn green. You can also click each step to see more details.
+
image::5-rag/running-pipeline.png[Running Pipeline]

. If you completed xref:5-rag/1-rag-in-playground.adoc[5.1. Try RAG in the playground] and did not specify a custom `VECTOR_STORE_NAME` in the pipeline, the new file will appear in the Playground automatically. Try asking: `I forgot my password and am locked out of my account. How do I reset it?`
+
image::5-rag/file-in-playground.png[File in Playground]
