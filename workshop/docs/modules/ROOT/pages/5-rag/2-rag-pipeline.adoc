= RAG ingestion pipelines

[role="_abstract"]
Now that you have used RAG from the Playground, you can do the same thing in code. +
There are two parts to it: one for ingesting the documents, and one for querying the model using those documents. +
Start here with the ingestion part, which you build as a pipeline so it is easy to trigger whenever new documents are added.

== Prerequisites

- Have a workbench set up according to xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench]
- Set up the playground as described in xref:2-just-a-model/2-playground.adoc[2.2. Using the Playground]

== Procedure

. Navigate to your workbench. If you don't have it open, you can find it through the {productname-short} Dashboard > Projects > your project.

. Inside the workbench you should see a file called `rag_pipeline.py`, this is a pipeline built with the Kubeflow Pipelines Python SDK. Open it to take a look at how it is set up. +
This pipeline contains the steps needed to chunk and ingest a new document into your RAG database, specifically this document: link:https://github.com/rh-aiservices-bu/hospital-helpdesk/blob/main/it_facilities_guide.pdf[it_facilities_guide.pdf,window=_blank] +
The document has already been uploaded into an S3 bucket (remember the one you set up during xref:1-setup/2-data-connections.adoc[1.2. Data connections]?) which the pipeline will download from.

. After you have looked through it, run the code to compile and execute the pipeline by clicking the play button in the top menu.
+
image::5-rag/run-pipeline.png[Run Pipeline]

== Verification

. If everything went well you should see this output:
+
image::5-rag/console-output.png[Console Output]

. You can now view the pipeline run in the {productname-short} dashboard. Select *Develop & train* > *Pipelines* > *Runs* from the left menu, then click the run that appears.
+
image::5-rag/pipeline-run.png[Pipeline Run]

. You can track the pipeline progress here. After a few minutes, both steps should turn green. You can also click each step to see more details.
+
image::5-rag/running-pipeline.png[Running Pipeline]

. If you completed xref:5-rag/1-rag-in-playground.adoc[5.1. RAG in the playground] and did not specify a custom `VECTOR_STORE_NAME` in the pipeline, the new file will appear in the Playground automatically. Try asking: `I forgot my password and am locked out of my account. How do I reset it?`
+
image::5-rag/file-in-playground.png[File in Playground]
