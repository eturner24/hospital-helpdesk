= Build an agentic workflow

[role="_abstract"]
In the RAG chapter you let the *OGX server* manage the agent loop through the Responses API.
Here, you move the loop to the *client* by using LangGraph, which gives you full control over state, tool execution, and human-in-the-loop decisions.

== Prerequisites

- The MCP ticketing server is deployed in xref:6-tools-agents/1-install-mcp.adoc[6.1. Deploy an MCP server].
- You have a workbench set up according to xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench].

== Procedure

. Open the notebook `3_tools.ipynb` in your workbench and complete it. Then, continue this tutorial.

== Verification

. At the end of the notebook, you see outputs similar to this.
You can also see the intermediate tool calls the agent makes and which tool it chooses. This is a smaller model, so it might not always choose or interpret the tools correctly.
