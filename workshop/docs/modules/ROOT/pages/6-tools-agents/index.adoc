= Tools and agents

[role="_abstract"]
You have already used tools in this workshop. In the RAG section, the model called the `file_search` tool autonomously. That autonomous tool use is what makes it *agentic* RAG as opposed to traditional RAG.
When you used the `file_search` tool in RAG you used it through OGX's tool calling. This is a transparent agentic loop that replicates what OpenAI exposes by default, which is good for simpler agents.
In this chapter you introduce a second tool, an IT ticketing system, and integrate it using *LangGraph*, a client-side orchestration framework.

For more on how OGX works with tools and when to use each framework, see link:https://developers.redhat.com/articles/2025/08/20/your-agent-your-rules-deep-dive-responses-api-llama-stack[Your agent, your rules: A deep dive into the Responses API with Llama Stack,window=_blank].

NOTE: OGX was previously called Llama Stack, so you might see the names used interchangeably.

To start, deploy a small MCP server that contains your ticketing tools: xref:6-tools-agents/1-install-mcp.adoc[6.1. Deploy an MCP server]
